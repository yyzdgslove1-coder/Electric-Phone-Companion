# Electric Phone Companion

电波手机的独立增强扩展，当前整合版本为 0.5.0。

依赖：SillyTavern 1.19、酒馆助手 4.x、原版电波手机 1.3.53。

## 功能

- 每卡人物名册与每聊天独立状态，沿用原版状态页和头像切换。
- 人物和好友分离，支持默认人物、纪念对象、头像和裁切。
- 保留未变化记录，最新有效状态变化置前。
- 各主要应用手动要求编辑，以及不写正文、新楼、追加最新楼。
- 公共／当前卡图库、原头像编辑器选图、A 表情导入。
- 银灰主题、精简选项文字、电脑和手机布局及位置记忆。

## 安装与更新

1. 原版电波手机和酒馆助手保持启用。
2. 扩展安装填写本仓库地址，选择仅为当前用户安装。
3. 第一次安装后刷新酒馆；以后从扩展管理更新。

从旧离线包迁移时，先移除 public/scripts/extensions/third-party/Electric-Phone-Companion 中的旧全局代码，否则它可能遮挡用户目录中的新版。
旧银灰酒馆助手脚本保持停用，增强包使用扩展管理的唯一启用开关。

仓库平时私有，安装／更新期间按需公开。
